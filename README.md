# CutFlow — бесплатный видеоредактор для Android (Kotlin + Jetpack Compose + OpenGL ES)

Сборка: залей папку в GitHub → вкладка Actions → **Build APK** → скачай артефакт `CutFlow-debug-apk`.
(Шрифты Google Fonts скачиваются в CI автоматически и попадают в APK.)

## Что умеет
- Таймлайн: видео и фото, обрезка, разрезание, дубли, порядок, скорость 0.25–4×, громкость, зеркало, поворот, масштаб, Ken Burns
- 13 фильтров + яркость/контраст/насыщенность
- 34 перехода, среди них **3D-куб (← и →)** и 3D-переворот карты; все — шейдеры GLSL
- Текст: ~30 шрифтов (10 системных + ~20 встроенных), цвет, обводка, тень, плашка, 6 анимаций
- 25 встроенных звуковых эффектов (синтезируются в коде) + своя музыка/звуки из файлов
- 11 встроенных шаблонов
- Холст: 16:9, 9:16, 1:1, 4:5, 3:4, 4:3, 21:9
- Отмена/повтор, предпросмотр со звуком
- Экспорт MP4: 720p / 1080p / 2K / 4K, 24–120 fps, H.264 или HEVC, 3 уровня качества.
  Если телефон не поддерживает параметры — подбираются ближайшие, итог показывается после экспорта.
  Файл сохраняется в Movies/CutFlow.

## Формат zip-пака (свои переходы, шрифты, звуки, шаблоны)
Вкладка «Паки» → «Установить пак». Структура (все папки необязательны):

```
pack.json                  {"name": "Мой пак", "author": "я"}
transitions/<id>.glsl      переход (формат gl-transitions)
transitions/<id>.json      {"name": "Красивое имя"}   (необязательно)
fonts/*.ttf, *.otf
sounds/*.mp3, *.wav, *.ogg, *.m4a, *.aac, *.flac
templates/*.json
```

### Переход (.glsl)
Нужно определить `vec4 transition(vec2 uv)`. Доступны: `getFromColor(uv)`, `getToColor(uv)`,
`progress` (0→1), `ratio` (ширина/высота), `PI`, `rand(vec2)`.
Параметры по умолчанию — как в gl-transitions: `uniform float count; // = 10.0`.
Любой переход с gl-transitions.com работает «как есть».

### Шаблон (.json)
```json
{
  "name": "Мой шаблон",
  "aspect": "9:16",
  "filter": "cinema",
  "transition": "cube_left",
  "transitionMs": 700,
  "clipMaxMs": 3000,
  "imageMs": 3000,
  "kenBurns": true,
  "sfxOnCut": "whoosh",
  "texts": [{"text":"Привет","font":"sans-serif-black","size":0.09,"color":"#FFFFFF",
             "startMs":0,"durMs":2500,"x":0.5,"y":0.3,"anim":"pop"}],
  "sfx": [{"id":"whoosh","atMs":0}]
}
```
Фильтры: none bw sepia vivid warm cool vignette invert fade cinema noir retro dream.
Анимации текста: none fade pop slide_up slide_left reveal bounce.
id перехода из пака — `pack:<имя пака>/<имя файла без .glsl>`.

Готовый пример: `examples/example_pack.zip`.

## Известные ограничения версии 0.1
- Проекты не сохраняются между запусками (только экспорт).
- Одна видеодорожка + дорожки текста и звука; нет наложения видео поверх видео (PiP), ключевых кадров, масок, субтитров по распознаванию речи.
- Шрифты из пака для предпросмотра звуков из пака работают только для 44.1 кГц (на таймлайн добавляется любой).
- Экспорт идёт на экране (не сворачивайте приложение).
